# Agroclimatología · Curso interactivo

Material de apoyo para un curso de Agroclimatología de pregrado en Agronomía. Cada tema combina explicación, un laboratorio interactivo y ejercicios que terminan en una decisión de campo. El curso está en construcción.

## Contenido

- `index.html`: portada del curso, con el plan de 16 semanas y el proyecto integrador.
- `tema-1-radiacion-solar.html`: Tema 1, radiación solar y nubosidad. Incluye un laboratorio para comparar ciudades de Colombia, una escena del Sol y la Tierra, un ejemplo resuelto, cinco ejercicios y tres retos con verificación automática.

## Cómo usarlo

Son páginas web sin dependencias externas: no necesitan instalación ni conexión a internet para funcionar. Para verlas en el computador, abre `index.html` con el navegador.

## Fuentes

- Allen, R.G., Pereira, L.S., Raes, D. y Smith, M. (1998). *Crop evapotranspiration: guidelines for computing crop water requirements.* FAO Irrigation and Drainage Paper 56.
- Contorno de Colombia: archivo `COL.geo.json` del repositorio público `johan/world.geo.json`, simplificado.

## Notas

- Los valores del laboratorio son modelos con fines didácticos, no mediciones de un año en particular.
- Las altitudes y coordenadas de las ciudades son aproximadas.
